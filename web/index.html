What the screening tells you

SolarConflux identifies candidate observation windows from heliocentric longitudes and optional latitude limits. It is a research prototype.

Geometry & grouping

Cone compares circular longitude separation. Opposition targets 180°; quadrature targets 90°. Groups share an anchor body: every pair in a multi-body group does not necessarily satisfy the condition.

Parker convention

Source longitude = body longitude + Ω × (radius − source radius) / wind speed. The rotation period is 25.38 days, source radius is 1,740,000 km, and footpoint tolerance is 5°. One uniform wind speed is used for all bodies.

Time & provenance

Times are UTC. Durations span the first to last matching sample; a single-sample event has zero duration. Boundaries are not interpolated. The chart is a projection of actual samples; it does not draw magnetic field lines. Imported provenance is supplied by the file and is not independently verified.

Browser operation

Live requests send the selected body names and UTC periods to the SolarConflux retrieval service, which fetches Horizons ephemerides. Imported files stay in your browser. Python screening runs here using the pinned Pyodide runtime. Run history stores trajectories, settings and results locally on this browser; download backups before clearing browser data. The Sun is displayed as the HCI origin and is excluded from alignment comparisons.
